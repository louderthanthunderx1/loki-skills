Skills organized into bucket folders under `skills/`:

- `engineering/` — daily code work
- `productivity/` — daily non-code workflow tools
- `general/` — cross-cutting behavioral guidelines
- `misc/` — kept around but rarely used

Each skill lives at `skills/<bucket>/<skill-name>/SKILL.md`. Reference material for a skill lives alongside it under `references/`.

Every skill must have an entry in the top-level `README.md` linking the skill name to its `SKILL.md`.

Each bucket folder has a `README.md` listing every skill in the bucket with a one-line description, skill name linked to its `SKILL.md`.
